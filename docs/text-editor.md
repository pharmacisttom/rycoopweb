# เครื่องมือเขียนข่าวและคำบรรยาย

หน้าแอดมินหลักมีเครื่องมือจัดรูปแบบสำหรับเนื้อหาข่าวฉบับเต็มและคำตอบ FAQ รองรับหัวข้อ ตัวหนา ตัวเอียง ขีดเส้นใต้ รายการ ลิงก์ ข้อความอ้างอิง ย้อนกลับ/ทำซ้ำ และดูตัวอย่าง การ์ดข่าวยังใช้สรุปย่อแยกจากข่าวฉบับเต็ม

ข่าวและ FAQ บันทึกลงฐานข้อมูลผ่าน API ที่จำกัดเฉพาะ super_admin และป้องกัน CSRF การลบ FAQ เปลี่ยนสถานะเป็น inactive ข่าวใช้การลบแบบ soft delete ระบบสมาชิกและแอดมินสมาชิกไม่มีสิทธิ์เผยแพร่ข่าว

คำบรรยายหน้าแรก ป๊อปอัป และข้อความตอบกลับใช้เครื่องมือในโหมดข้อความธรรมดาเพื่อรักษารูปแบบข้อมูลเดิม การบันทึกส่วนเหล่านี้ยังใช้วิธีเดิมของแต่ละหน้า ไม่ได้เปลี่ยนเป็นระบบ CMS บนฐานข้อมูลทั้งหมด

ใช้ Quill 2.0.2 โดยตรึงรุ่นเพราะ npm audit แจ้งช่องโหว่ export HTML ในรุ่น 2.0.3 เนื้อหาที่จัดรูปแบบกรองด้วย DOMPurify ก่อนแสดงและ HTML Purifier ก่อนบันทึก อนุญาตเฉพาะแท็กข้อความและลิงก์ที่กำหนด ไม่รับสคริปต์ iframe รูปภาพฝัง หรือ CSS จากการวางข้อความ ภาพประกอบข่าวยังใช้ช่องรูปภาพเดิม

## อัปเดต VPS

ใช้ขั้นตอนสำรองและดึงโค้ดตามคู่มือ deployment เดิม จากนั้นต้องติดตั้งทั้ง PHP และ JavaScript dependencies:

```bash
composer install --no-dev --optimize-autoloader --no-interaction
npm ci
npm run build
```

ชุดนี้ไม่เพิ่มตารางหรือ migration เปิดหน้าแอดมินแล้วโหลดหน้าใหม่หนึ่งครั้ง หลังจากนั้นใช้เครื่องมือในเมนูข่าว FAQ และคำบรรยายได้ตามปกติ

## ตรวจสอบ

- `php tests/RichTextServiceTest.php`: รูปแบบข้อความ ลิงก์ และการกรอง XSS
- `php tests/RichTextPublicationTest.php`: บันทึกข่าวและ FAQ จริงในฐานข้อมูลทดสอบแยก ตรวจเนื้อหาฉบับเต็มจาก public API และปฏิเสธข้อความว่าง
- `php tests/SecurityRegressionTest.php`: ตรวจสิทธิ์ API รวมถึง FAQ ที่เพิ่ม
- `npm run build`

ทดสอบตัว Editor ในเบราว์เซอร์ด้วยข้อความภาษาไทย ตัวหนา และตัวอย่างก่อนโพสต์ รวมถึงขนาดหน้าจอมือถือ ไม่มีการเผยแพร่ข่าวทดสอบบนระบบจริง ข้อแจ้งเตือน npm audit ที่เหลืออยู่ใน React Router และชุดพัฒนาเดิมต้องแยกอัปเกรดและทดสอบในงานถัดไป
