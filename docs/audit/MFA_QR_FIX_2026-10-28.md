# แก้ QR ตั้งค่า MFA — 28 ตุลาคม 2569

Base: Test commit 2d400a7; branch codex/fix-mfa-qr
แก้ blocker ที่รายงานใน PR #5 โดยไม่เปลี่ยนบัญชีจริง, MFA secret, encryption key, session policy หรือฐานข้อมูล และยังไม่ได้ deploy VPS

## สาเหตุและการแก้

Encoder เดิมต่อ data/error-correction เป็นก้อนเดียวและไม่มี version information สำหรับ QR version 7 ขึ้นไป ทำให้ภาพ SVG สร้างได้แต่สแกน OTP URI ตัวอย่างไม่ได้
ยืนยันก่อนแก้ด้วย jsQR 1.4.0: HELLO อ่านได้ แต่ URI version 7 อ่านไม่ได้ ในขณะที่ QR อ้างอิงของ payload เดียวกันอ่านได้

- คง public API svg()/dataUri() และ ECC constants ของ QrCodeGenerator แต่เปลี่ยน core encoding เป็น bacon/bacon-qr-code 3.1.1 (ล็อกใน composer.lock; constraint ^3.0)
- ใช้ core Encoder และวาด SVG unit modules ภายในเซิร์ฟเวอร์ ไม่ใช้บริการ QR ภายนอก ไม่ต้องติดตั้ง Imagick/GD/XMLWriter สำหรับเส้นทางนี้
- รองรับ Reed–Solomon blocks/interleaving, version information, UTF-8, QR versions ถึง 40 และปฏิเสธข้อมูลเกินความจุแทนตัดข้อมูลเงียบ ๆ
- รักษา quiet zone อย่างน้อย 4 modules; ขนาด SVG เป็นขั้นต่ำที่ขอ ปัดขึ้นเป็นจำนวนพิกเซลเต็มต่อ module อย่างน้อย 4 px/module ป้องกันภาพแน่น/การย่อขยายที่ทำให้ตัวอ่านล้มเหลว
- หน้า MFA แสดงภาพตามขนาด intrinsic และย่อให้เข้าหน้าจอเมื่อจำเป็น ไม่บังคับภาพเป็น 240 px แบบเดิม
- เพิ่ม jsqr 1.4.0 เป็น dev dependency เท่านั้น และ regression ที่อ่าน pixel data ของ SVG จริงกลับเป็น OTP URI
- เพิ่ม MfaRateLimitTest และ QR unit tests ใน PHP CI และ QR round-trip ใน frontend CI พร้อม Composer dependencies/PDO SQLite/iconv สำหรับ fixtures

## เตรียม TEST/VPS

1. ตรวจ revision และสถานะ CI ของ PR ที่แก้ QR ให้ผ่าน ก่อนนำเข้า Test ไม่ merge Production อัตโนมัติ
2. ใช้ release/checkout TEST ที่แยกจากระบบจริง ตรวจ path/Nginx/โดเมนตามแผนเดิม ไม่เปลี่ยน .env หรือถอด Basic Auth เพื่อให้ทดสอบผ่าน
3. ต้องติดตั้ง Composer จาก lockfile ก่อนเปิดใช้ source ใหม่: composer install --no-dev --optimize-autoloader --no-interaction --prefer-dist ตรวจ PHP CLI/FPM >=8.2 และ ext-iconv
4. ขั้น build/test ต้องมี Node dependencies: npm ci แล้ว npm run build หากรัน QR regression ใช้ node tests/QrCodeRoundTripTest.mjs และต้องมี PHP/PDO SQLite สำหรับ fixtures
5. การแก้ชุดนี้ไม่มี migration ใหม่ ห้ามรัน db:migrate/db:seed/drop/truncate หรือ reset MFA เพียงเพื่อแก้ QR ถ้า schema เดิมยังไม่ครบให้แยกตรวจและขออนุมัติตามแผน migration เดิม
6. รักษา APP_KEY/TWO_FACTOR_ENCRYPTION_KEY เดิมและข้อมูล TOTP/recovery ทั้งหมด บัญชีที่ใช้งาน Authenticator อยู่แล้วไม่จำเป็นต้องลงทะเบียนใหม่
7. UAT ด้วยบัญชีทดสอบ: enroll → สแกน Authenticator → confirm → เก็บ recovery → logout → login/TOTP → recovery รวม wrong code/429/expiry/replay/session revoke บน MySQL TEST และ browser จริง
8. ให้ผู้อนุมัติพิจารณา Production หลัง TEST/UAT ผ่าน ชุดนี้ไม่ได้แก้ public-site 404 หรือข้าม TEST nginx 401

## Rollback

ย้อน source + composer/package lockfiles + vendor/build artifacts ให้เป็น release ก่อนหน้าด้วยกัน ไม่ลบข้อมูล MFA ไม่เปลี่ยน key และไม่ rollback schema อัตโนมัติ
หากกลับไป encoder เดิม ปัญหา QR ตั้งค่าใหม่จะกลับมา; คงบัญชีที่ลงทะเบียนสำเร็จแล้วและหยุดเปิด enrollment ใหม่จนกู้ release ที่สแกนได้
